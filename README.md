# README

## Application defaults

- Time zone: `America/Sao_Paulo`
- Interface locale: English (`en`)
- Reporting currency: Brazilian real (`BRL`)
- Development and test database: SQLite
- Styling: Tailwind CSS

`BRL` is the reporting-currency default used when presenting portfolio values.
Currency conversion and exchange-rate behavior are outside the current
foundation scope.
